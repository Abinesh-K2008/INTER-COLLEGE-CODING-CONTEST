About the Contest

The Inter-College Coding Contest is a platform for students to demonstrate their programming skills, logical thinking, and problem-solving abilities. Students from different colleges can participate and compete for exciting prizes.

Contest Rounds

  1. Round 1: Online Quiz

    Test your knowledge of programming and computer science.

  2. Round 2: Coding Challenge

    Solve programming problems within the given time limit.

  3. Round 3: Final Debugging Round

    Find errors, debug programs, and solve advanced problems.

Programming Languages

Participants can use any one of the following languages:

  • C
  • C++
  • Java
  • Python

Contest Rules

  1. Participants must be students of a recognized college.
  2. Participants must register before the deadline.
  3. Each participant must carry a valid college ID card.
  4. Students must not use mobile phones or engage in unfair practices.
  5. Use only the permitted programming languages.
  6. The judges' decision will be final.
  7. Participants must complete each round within the time limit.

Prizes

  • First Prize - Gold Medal and Certificate
  • Second Prize - Silver Medal and Certificate
  • Third Prize - Bronze Medal and Certificate
  • All participants will receive participation certificates.
